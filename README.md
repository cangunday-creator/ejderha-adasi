# Ejderha Adası

Bu proje, hem komut satırından hem de web tarayıcısında oynanabilen bir metin tabanlı macera oyunudur.

## CLI oyun

Komut satırından çalıştırmak için:

```bash
python macera.py
```

## Web oyunu

Web sayfasında oynamak için:

```bash
python server.py
```

Sunucu çalıştığında tarayıcı otomatik olarak açılacaktır. Eğer açılmazsa elle `http://127.0.0.1:8000` adresini ziyaret edin.

## Kaydetme / yükleme

CLI modunda oyun ilerlemesini kaydetmek için hikaye modu içindeyken "Oyunu kaydet" seçeneğini kullanabilirsin. Kaydedilmiş oyunu ana menüden "Kaydedilmiş oyunu yükle" seçeneğiyle yükleyebilirsin.

## Özellikler

- Hikaye modu
- Envanter ve altın sistemi
- Tamamon koleksiyonu
- Ada keşfi ve savaş sistemi
- Basit web arayüzü
